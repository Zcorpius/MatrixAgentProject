# Matrix system API compile stub

`framework-lineage-grus.jar` is the `framework-minus-apex` turbine jar generated by the same
LineageOS source tree and build output as the target `grus` image. It is versioned with this
project on purpose: `ServiceManager` is a system API, so a clean checkout must compile against
the exact framework contract of the image that will host this platform-signed APK. It is not a
public SDK dependency and must never be copied into the APK (`compileOnly` only).
