# 雪乃悬浮入口接入与验证

日期：2026-09-27。Launcher 将原先的 `M ···` 圆形入口替换为透明雪乃角色，点击展开原会话面板、拖动贴边。Host 的任务执行、交接 ACK、取消及消息协议保持原有语义。

## 模块边界

| 组件 | 职责与所有权 |
| --- | --- |
| `LauncherApplication` | 拥有共享素材仓库，预热中立帧和待机；内存回调清理缓存，受控关闭时释放仓库 |
| `LauncherExecutorRegistry.petDecoding` | 独立单线程、8 个排队任务的解码通道；不占用 SDK 或交接线程 |
| `PetSpriteCatalog` | 解析本包 schema v1，校验必需动作、尺寸、路径、逐帧时长及总时长 |
| `PetSpriteRepository` | 合并同动作的并发请求，后台读取 PNG，主线程投递结果，按位图 allocation bytes 限制 LRU 为 3MiB |
| `SpriteTimeline` | 不依赖 Android 的帧采样；按可见播放时间和原始逐帧时长定位当前帧及下一边界 |
| `YukinoPetView` | 等比例绘图、播放/暂停、单次动作、状态角标；关闭订阅和定时回调，不持有 Activity |
| `OverlayPetState` | 将任务状态与结构化执行阶段映射为视觉意图，不读取本地化进度文本 |
| `OverlayWindow` | 继续负责 WindowManager、点击、拖动、输入焦点、面板与隐藏状态；显式向角色传递播放许可 |

仓库通过构造器从 Application → Controller → Window → View 注入。没有静态全局位图、View 内线程池或新增图片框架。采用项目 Java 17 基线的 record、switch expression；新增生产代码经过最低 API 28 的 lint 检查。

`OverlayConversationPresenter.State` 新增 `primaryMessageId` 和 `runtimeStage`，前者区分任务轮次，后者反映 Host 的真实阶段。`HandoffProtocol.IDLE` 是外部 UI 的输入门控，不代表任务已空闲，因此不作为角色待机依据。

## 素材

素材来自用户提供的 `yukino-android` 包，位于 `matrix-agent-launcher/src/main/assets/yukino`。74 张 PNG 和原始 `animations.json` 按字节复制；源包和本地文件的 SHA-256 比对结果保存在验证目录的 `asset-integrity.json`。

- PNG：192×208，57 个动作帧、16 个视线方向、1 个中立帧。
- JSON：9 种动作及原始逐帧时序；`running` 是工作/思考，不是左右奔跑。
- 当前运行时只读取 PNG 序列。JSON 中的 atlas 字段保留来源说明；原始 `spritesheet.webp` 不随 APK 重复打包，也不会在运行时解码。
- 已启用拖动时的左右奔跑、16 方向触点注视和挥手；未启用自主移动。
- 没有重绘、裁切或预先缩放 PNG。绘图时采用相同比例的 96×104dp 画布和位图过滤。

## 状态与时序

| 任务事实 | 动作 | 播放策略与标记 |
| --- | --- | --- |
| 初始加载 | `neutral` | 静态中立；中立帧尚不可用时以 M 保留可点击入口 |
| 未知/已接收/排队/正在取消 | `waiting` | 循环 |
| 非终态断线 | `waiting` | 循环，保留连接异常标记 |
| 规划/执行/运行中 | `running` | 循环 |
| 完成 | `jumping` → `idle` | 跳跃一次后循环待机，完成角标持续显示 |
| 失败/拒绝 | `failed` | 完整播放一次并停留末帧，失败角标持续显示 |
| 执行结果未知 | `review` | 循环，问号角标；不将未知结果当作失败 |
| 已取消 | `idle` | 循环，取消角标 |

终态事实优先于连接状态，防止断线/重连导致完成动作再次播放。相同轮次、相同动作的 `render()` 只更新展示信息，不重置动画；新主消息可以重新播放单次动作。

播放器按 `SystemClock.uptimeMillis()` 累计可见播放时间，暂停时保存进度，恢复后从原位置继续。回调迟到时直接采样正确帧，不累计帧延迟。每次仅在下一帧边界安排回调，不以 60fps 持续刷新。完成动作转入待机后仍保留逻辑上的完成状态。

### 拖动跑步覆盖

`running-left` / `running-right` 由真实拖动触发，保持原来的每方向 8 帧、1060ms 循环时序。`OverlayDragGesture` 在越过系统 touch slop 后才提供移动；水平方向采用极值点加同一阈值的回转判断，既能在尚未返回按下位置时正确转身，又能过滤细微抖动。上下拖动沿用最近朝向，首次默认为右。

按下时在已有素材仓库中异步预取两个跑步动作，不阻塞触摸线程。`YukinoPetView` 保存被覆盖动画的动作、位图引用、帧索引及已播放时间，再切换到跑步；持续同方向 MOVE 不重启动画。松手或取消恢复保存的播放位置，因此已经回到 idle 的完成动作、已经停留末帧的失败动作都不会重播。尚未完成的单次动作在恢复后继续播放剩余部分。

拖动期间 `present()` 仍接收最新任务状态与角标；任务轮次/动作改变时更新恢复目标，保持当前跑步直到松手。方向切换或快速松手后，旧解码结果仍受订阅取消和 generation 校验保护。

`ACTION_UP`、`ACTION_CANCEL`、第二指按下、失去交互许可、隐藏或展开面板都会结束覆盖。点击及标题栏拖动继续走原交互，角色窗口的贴边位置仍按实际宽度计算。

## 生命周期与失败处理

### 全屏注视与挥手

详细架构和设备证据见[触点注视与挥手验证](verification/yukino-interaction-2026-09-27/README.md)。

| 场景 | 行为 |
| --- | --- |
| 触碰屏幕任意位置，包括其他应用 | 朝角色头部到触点的方向选择 16 个 `look` 姿态之一；中心 12dp 内使用中立帧 |
| 手指移动 | 每 33ms 至多发送一次 MOVE，方向边界加 3° 滞回；姿态静止显示，不循环播放 16 帧 |
| 抬起第一根手指 | 保持最后方向 800ms 后恢复原任务动作；连续触碰重置保持时间 |
| 多指 | 仅跟随最先按下的指针；该指针抬起后不转移到其他手指 |
| 会话首次可见 / 离开至少 5 分钟后再出现 | 挥手一次后恢复任务；展开收起面板、短暂切换不重复挥手 |
| 拖动角色 | 左右跑步优先，松手直接恢复任务动作，不恢复已打断的注视或挥手 |
| 新的完成、失败、待确认结果 | 打断注视或挥手；首次结果动画播放期间阻止注视抢占；拖动结束后显示最新结果 |
| 展开面板、隐藏、锁屏、切换用户、断线或关闭 | 停止触点观察；丢弃旧回调，解除临时注视并保留任务事实 |

挥手只在没有状态角标且没有正在优先展示的结果时开始。临时动作不改变任务角标，也不重播已完成的任务动画。问候历史在 Launcher 进程内按会话记录，最多保留 64 项；进程重启后重新视作首次出现。

Host 使用目标 ROM 的 `InputMonitor` 接收输入副本，始终 `finishInputEvent(event, false)`，不调用 `pilferPointers`；没有覆盖全屏的透明触摸层，不使用会拦截其他应用输入的无障碍触摸监听。观察仅对同一 Android 用户、可信 Launcher UID 开放；客户端每 10 秒续约，Host 独立执行 30 秒租约回收和 Binder 死亡清理。

新增 `IOverlayInteractionService` / `OverlayInteractionManager` 与 Parcel schema 13。Launcher 仅依赖发布 SDK；原始坐标只在内存中经过 Host → SDK → Launcher，未写日志、数据库或发送给模型。服务调用、图片解码、UI 分别由有界独立执行通道和主线程负责。Android 15 以下不发布该服务，原有角色、任务动画与拖动仍可工作；平台输入 API 要求匹配 ROM 的 framework 与平台签名权限。

- 窗口未提交 ownership 时可以显示角色，但禁用交互与动画推进，沿用原有 ACK 门控。
- 面板展开、父视图隐藏、窗口脱离或播放许可关闭时，移除播放回调。Controller 的屏幕关闭/切换用户处理继续销毁窗口。
- View 关闭时取消素材订阅、清理帧/中立引用及所有播放回调。已排队的解码可以结束并填充共享缓存，不能重新唤醒关闭的 View。
- 快速状态切换采用请求取消和递增 generation 两层约束；旧动作的异步结果不能替换新动作。
- 解析、IO、解码或线程池拒绝导致加载失败时，保留中立图/文字入口与原操作，记录 `MatrixPet` 日志；图片失败不升级为窗口交接失败。
- LRU 淘汰只丢引用，不调用 `Bitmap.recycle()`，避免正在显示的窗口或回滚保留的旧窗口访问被回收的位图。
- 3MiB 是共享缓存容量，不是进程内所有位图内存的硬上限；当前 View、中立图和正在解码的数据可能额外持有引用。

## 窗口几何与可访问性

收起状态去掉旧圆形背景和根窗口阴影；展开面板恢复原有阴影。初始化、每次尺寸配置和贴边都使用角色实际宽高，右侧位置为屏幕宽度减窗口宽度再减边距，贴边方向根据窗口中心判断。

角色继续通过 `WindowDrag` / `OverlayDragGesture` 处理拖动阈值和取消手势；正常点击最终调用 `performClick()`。无障碍节点声明 Button 角色，描述包含“Agent 雪乃”、当前进度、点按与拖动提示。

触摸区域仍是 96×104dp 矩形。素材透明区域不自动穿透；窗口范围外沿用现有 `FLAG_NOT_TOUCH_MODAL` 路由。尚未实现逐像素触摸区域。
